# Year in Frames

아이폰 또는 컴퓨터 사진을 연도별로 불러와 월별·여행별 포토북을 자동 구성하는 로컬 웹 앱입니다.

## 실행

```bash
source ~/.nvm/nvm.sh
npm install
npm run dev -- --host
```

터미널에 표시된 `http://localhost:5173`을 Windows의 최신 Chrome 또는 Edge에서 엽니다.

## 사진 가져오기

컴퓨터에 있는 샘플 사진도 **파일 또는 폴더 직접 선택**으로 불러올 수 있습니다. 사진의 촬영 연도와 화면에서 선택한 연도가 같아야 합니다.

아이폰을 사용하는 경우:

1. 아이폰에서 **설정 → 사진 → Mac 또는 PC로 전송 → 원본 유지**를 선택합니다.
2. 아이폰을 컴퓨터에 연결하고 잠금을 해제한 뒤 컴퓨터를 신뢰합니다.
3. 앱에서 아이폰의 `Internal Storage/DCIM` 또는 미리 복사한 사진 폴더를 선택합니다.

## 스마트 배치

- 사진을 가져올 때 인물, 풍경, 음식, 동물 등 장면과 선명도·초점 위치·시각적 중요도를 분석합니다.
- 중요한 사진은 큰 영역에, 풍경은 넓은 영역에 우선 배치하고 인물의 초점이 잘리지 않도록 조정합니다.
- **스마트 배치**를 다시 누르면 같은 사진으로 다른 편집 템플릿 조합을 만들 수 있습니다.
- 사진 분석은 브라우저 안에서 실행되며 사진 자체는 외부 서버로 전송되지 않습니다. 최초 분석 모델 다운로드에는 인터넷 연결이 필요합니다.

사진과 작업 내용은 브라우저의 IndexedDB에 저장됩니다. 브라우저 사이트 데이터를 삭제하면 작업도 삭제되므로 완성본은 PDF로 내보내 보관하세요.

## 제한 사항

- 실시간 사진 MOV가 HEVC 형식이고 Windows에 해당 코덱이 없으면 브라우저에서 재생되지 않을 수 있습니다.
- 여행 감지는 GPS가 기록된 사진을 기준으로 하며 위치 이름과 지도에는 OpenStreetMap/Nominatim 연결이 필요합니다.
- PDF는 최대 50페이지, 300dpi 기준입니다. 사진이 많으면 내보내기에 시간이 걸릴 수 있습니다.
